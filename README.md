## Warning
If you run this script inside an IDE, it may show your password while you're typing it in so make sure that people don't see your screen or use the operating system's command line.
## Good to know
This script saves your session in a state.json file in the same directory as the script. So don't delete this file if you don't want to type in your email and password again.
## How to run
1. Install python and pip
2. Install playwright
```
  pip install playwright
```
3. Run the program
```
  python main.py
```
